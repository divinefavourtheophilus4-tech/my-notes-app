# My Notes App

## Project Description

GROUP 2 Notes App is a simple web application that allows us to create, edit, delete, and search through notes.

The application uses JavaScript to manage the notes and Local Storage to save the notes in the browser. This means that saved notes remain available even after the page is refreshed.

## Features

* Create new notes with a title and content
* Edit existing notes
* Delete notes
* Search notes by title or content
* Save notes using Local Storage
* Validate input to prevent empty notes

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the **+ New Note** button to create a note.

## Project Structure

* `index.html` — Contains the structure of the Notes App.
* `style.css` — Contains the styling and layout.
* `script.js` — Contains the application's functionality.
* `README.md` — Contains information about the project.
